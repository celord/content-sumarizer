# Glossary

**Link**: A TikTok video URL a user sends to the bot's chat. Each Link triggers one processing run.

**Transcript**: The spoken text of a video, taken from TikTok's subtitles when they exist, otherwise produced by speech-to-text.

**Analysis**: What the model extracts from a Transcript: summary, key ideas and tags.

**Note**: One Obsidian-compatible Markdown file per Link, holding frontmatter and the Analysis. _Avoid_: summary (a summary is one part of a Note).

**Vault**: The Obsidian folder that Notes are written into.
