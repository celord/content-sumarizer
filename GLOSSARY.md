# Glossary

**Link**: A content link from a supported Platform that a user sends to the bot's chat. Each Link triggers one processing run.

**Platform**: A site the bot accepts Links from: TikTok or X (Twitter). Each Note records its Platform.

**Transcript**: The spoken text of a video, taken from TikTok's subtitles when they exist, otherwise produced by speech-to-text.

**Source Text**: The text an Analysis is made from: the Transcript for a video, the tweet text (plus any quoted tweet) for X.

**Analysis**: What the model extracts from a Source Text: summary, key ideas and tags.

**Note**: One Obsidian-compatible Markdown file per Link, holding frontmatter and the Analysis. _Avoid_: summary (a summary is one part of a Note).

**Vault**: The Obsidian folder that Notes are written into.
